# 🎮 Tic Tac Toe AI — Minimax Algorithm

An unbeatable Tic Tac Toe AI built using Python with the Minimax algorithm.
Built as **Task 2** of the **CodSoft Artificial Intelligence Internship**.

---

## 📌 Features

- 🤖 Unbeatable AI using Minimax Algorithm
- 🎮 Human vs AI gameplay
- ✅ Win, Lose, Draw detection
- 🔄 Clean board display after every move
- ❌ Invalid move handling
- 🎯 AI always plays the optimal move

---

## 🧠 How Minimax Works

```
AI thinks ahead — checks ALL possible moves
      ↓
Assigns scores to each outcome:
  AI wins  →  +1
  AI loses →  -1
  Draw     →   0
      ↓
Picks move that MAXIMIZES AI score
while MINIMIZING human score
      ↓
Result → AI is completely unbeatable!
```
